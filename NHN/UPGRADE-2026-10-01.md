# NHN hardening upgrade — 2026-10-01

This package is based on `wed---nhn-main(8).zip` root project. The accidental nested duplicate project was removed.

## Applied
- Exam attempts are server-authoritative: visitor ownership, server deadline, expiry, resume, autosave validation, question/option membership checks and idempotent answer uniqueness.
- Added migration `0023_security_integrity.sql`; existing migrations remain unchanged.
- CMS publish requires `content.publish`; saved HTML is sanitized server-side.
- Initial setup supports `SETUP_SECRET`; account/setup email and password validation hardened.
- PBKDF2 new hashes use 210k iterations; legacy 100k hashes remain compatible and upgrade on successful login.
- Password changes revoke sessions; stale sessions/rate-limit rows are opportunistically cleaned.
- Public form validation, honeypot and rate limiting added.
- Media/public-document upload allowlists and tighter size limits added; referenced media cannot be deleted; R2 reconciliation endpoint added.
- Admin navigation/homepage JSON is validated; logo, maintenance mode, homepage section order/visibility, SEO title/description now affect public UI.
- Duplicate nested project removed.

## Validation performed
- All 23 migrations applied sequentially to a fresh SQLite database.
- Result: 260 exams, 13,000 questions, 52,000 options.
- API TypeScript passed `tsc` using local Cloudflare interface shims.
- Changed TSX files passed syntax-oriented TypeScript checks.

## Environment limitation
Full `npm install`/Vite production build could not be completed in the audit environment because npm registry dependency installation timed out. Run `npm install && npm run lint && npm run build` in CI/deployment before production release.

## Deployment note
For a brand-new database, configure a Cloudflare secret named `SETUP_SECRET` before first initialization. Do not place the secret in `wrangler.jsonc`.
